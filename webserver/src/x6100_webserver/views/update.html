Update

The radio installs a newer OpenX6X00 by itself: the GUI, the web pages, the helpers and their data, from the GitHub releases of the repository it was built from (its own) or from a bundle file. The files are checked against the bundle's own list of their SHA-256 sums, the previous version is kept, and the radio software restarts at the end (about a minute). A version that does not come up is put back automatically. A release's bundle also carries the SD card's kernel (with its modules, the WiFi driver among them) and U-Boot: they are written only when ticked below, only to the SD card the radio started from (never its internal memory), the old ones kept, and start at the next power-on.
